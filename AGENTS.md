# AVA Studio installation entry point

A request to install this repository authorizes routine installation and dependency setup. Read INSTALL.md and execute the work, rather than giving the user a list of terminal commands.

Fetch the repository files together (clone or download its source snapshot); install.sh needs install.py beside it. Do not execute an HTML GitHub page. The app ZIP comes from the published release via install.py. Verify hashes before extraction. Do not bypass verification, fabricate files or modify the embedded expected hash to accept a failed download.

Check Apple Silicon macOS 14+, Python 3.11+ and Codex availability. Install missing prerequisites from official sources when permitted. Ask only for human login, necessary OS approval or an actual blocker. Never request API keys or passwords in chat, disable platform security, overwrite an existing installation, or run paid content generation during setup.

Use a new permanent destination, separate from this small bootstrap repository; default ~/AVA Studio. Run bash install.sh (optionally --directory with a new destination). If setup fails after extraction, diagnose and resume Setup.command inside the existing extracted application rather than overwriting or re-downloading it.

Then read the installed AGENTS.md and INSTALL-AGENT.md. Verify dependency availability, local UI and Chromium/render preflight without paid calls. Open Studio and leave its server running. Tell the user where it is installed, how to reopen it, and where to add keys. Report blockers accurately; UI launch does not prove a complete render pipeline.
