# AVA Studio

**From idea to finished reel.** Find ideas, write scripts, edit footage and create animated videos in one workspace.

## Install

Open the Codex desktop app and send:

> Read https://github.com/winloter911-source/ava-studio and install AVA Studio following AGENTS.md and INSTALL.md.

The agent downloads the installer files, installs missing prerequisites, verifies the published release archive and configures the app. Complete any sign-in or system permission prompts if asked. Existing folders are never overwritten.

**Requires Apple Silicon Mac (M1 or newer), macOS 14+, internet and your own Codex access.** Windows and a Claude execution backend are not supported by this build.

## Your tools

- **Analyze Instagram:** discover ideas using your Apify account.
- **Create Scripts:** write from an idea or adapt a reference.
- **Edit Footage:** automatic or manual editing.
- **Animated Reel:** create videos from audio, scripts or references.

Add your own Apify and ElevenLabs keys in Settings. Services may charge your account. Roman's visual character is included; personal voice credentials are not.

## Updating from v1.0.0

Download AVA-Studio-v1.0.1-Fix.zip from the v1.0.1 release. Close Studio, extract the repair and ask your agent to follow its README.md for your existing installation. Your keys, settings and projects are preserved; application files are backed up.
